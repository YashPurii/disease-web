# Disease Web frontend

This folder contains the React/Vite interface for the finished Disease Web slice. The root [README](../README.md) is the project-level guide.

Run from this directory:

```powershell
npm install
npm run build
npm run preview -- --host 127.0.0.1 --port 4173
```

The app consumes the committed graph bundle at `src/data/disease-web.json`, which is regenerated by `scripts/export_web_data.py` after a data refresh.
